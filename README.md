# ORJAFLOW Music Downloader 1.1.0

Developed by Orjani Ayoub.

ORJAFLOW est un programme Windows qui enregistre l'audio d'un lien YouTube que vous avez le droit de télécharger. L'interface est en français. Il ne demande pas les droits administrateur et n'envoie aucune donnée.

Le code source n'est pas publié. Téléchargez uniquement l'installeur.

## Télécharger

1. Ouvrez **Releases**.
2. Téléchargez `ORJAFLOW-Setup.exe`.
3. Lancez-le, puis cochez **Lancer ORJAFLOW**, ou ouvrez le raccourci sur le bureau.

Python n'est pas nécessaire. FFmpeg est déjà dans l'installeur.

## Utilisation

1. Collez un lien de vidéo ou de playlist YouTube.
2. Choisissez le format : MP3, M4A, OPUS ou FLAC.
3. Choisissez le dossier de destination.
4. Cliquez sur **Télécharger**.
5. Pour une playlist, les titres sont cochés. Décochez ceux que vous ne voulez pas. Ils sont enregistrés dans un sous-dossier au nom de la playlist.
6. **Ensemble** (1 à 5) règle combien de titres partent en même temps.
7. Sur chaque carte : **Lire**, **Pause**, **Reprendre**, **Annuler**, **Réessayer**, **Dossier** ou **Retirer**.
8. Le lecteur en bas lit le morceau, passe au précédent ou au suivant, règle le volume, l'aléatoire et la répétition.
9. **Bibliothèque** cherche, trie, filtre et affiche les morceaux en liste ou en grille.
10. **Historique** filtre les résultats et peut réessayer les échecs.
11. **Paramètres** s'enregistrent tout seuls.

## À savoir

- La vitesse dépend de votre connexion et de YouTube.
- 320 kbps et FLAC n'améliorent pas une source YouTube déjà compressée.
- Gardez uniquement les contenus que vous avez le droit de télécharger.
- ORJAFLOW ne contourne pas une connexion obligatoire, un contrôle anti-robot, ni une restriction géographique.
